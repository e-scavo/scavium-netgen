# Notes

Operational observations from the first SCAVIUM testnet deployment.

## Key Observations

1. Validators may enter round changes during the first startup.
2. Restarting validators in a short window can help consensus convergence.
3. Separating node keys from operational accounts simplifies operations.

## Validation Checklist

The following items were verified:

- block production active
- peer connectivity stable
- RPC nodes functional
- transaction included in block
- balances updated correctly

## Future Improvements

The next development stage includes operational tooling for interacting with the network.
